# В'кусно — интернет-магазин ресторана с доставкой (Нижний Новгород)

Node.js 24+ · Express · SQLite (встроенный `node:sqlite`) · без сборки фронтенда.

## Запуск
```bash
npm install
cp .env.example .env          # заполнить
npm run create-admin -- you@example.com     # пароль сгенерируется и будет показан один раз
npm start                     # сайт: http://localhost:3000, админка: /staff (ADMIN_PATH)
npm test                      # тесты бизнес-логики (31)
```
Сквозной тест в браузере (нужен Edge/Chrome): `node tests/e2e.js <папка_скриншотов>`.

## Что где
- `server/lib/pricing.js` — единственное место, где считаются цены, скидки, доставка (правила A/B/C, минимум 1 500 ₽, индикатор).
- `server/lib/geo.js` — геокодирование (Яндекс при ключе, иначе OSM), граница Автозаводского района (OSM relation 2006088), радиус 5 км, подписанные токены адреса.
- `server/lib/orders.js` — оформление заказа: серверный пересчёт, идемпотентность, статусы.
- `server/lib/payments.js` — заготовка платёжного модуля (онлайн-оплата выключена).
- `server/lib/mail.js` — письма (SMTP из `.env`).
- `admin/` — админ-панель (SPA), `public/` — витрина, `data/` — база и ключ (не в git).

## Перед запуском (чек-лист владельца)
1. Задать `.env` (SITE_URL, ADMIN_PATH, SMTP_*), создать администратора, **сменить пароль из консоли на свой**.
2. Админка → Настройки: проверить телефон (взят со страницы Яндекс.Карт), добавить email, адрес отправителя и «куда присылать заказы», включить почту и нажать «Отправить тестовое письмо».
3. Админка → Меню: у скрытых блюд (шашлык из вырезки/корейки/рёбрышек/голени/баранины, чай) в PDF не было цен — задать цены и включить. Загрузить фото блюд (сейчас — заглушка с логотипом). Проверить «Хиты» (расставлены как пример).
4. Админка → Страницы: заполнить реквизиты и юридические тексты (в них отмечено `[…]`), показать юристу. Политика, согласие и условия — черновики.
5. Выбрать способы оплаты (Настройки → Оплата). Онлайн-оплата не подключена.
6. Геокодер: для production получить ключ Яндекс.Геокодера (`YANDEX_GEOCODER_KEY`) — публичный Nominatim ограничен 1 запрос/сек и не предназначен для высокой нагрузки.
7. Развернуть за HTTPS (nginx/Caddy), включить `NODE_ENV=production`, регулярно копировать `data/shop.db`.
8. Если нужны кассовые чеки (54-ФЗ) — подключить онлайн-кассу отдельно: письмо с подтверждением заказа чеком не является.

## Деплой на Render (инструкция)
1. Создайте на GitHub **приватный** репозиторий и загрузите проект (`git remote add origin <url>` → `git push -u origin main`). Файл `.env` и папка `data/` в репозиторий не попадают.
2. Render → **New + → Blueprint** → выберите репозиторий. Render прочитает `render.yaml` и создаст веб-сервис с диском `/data` (нужен платный тариф Starter: на бесплатном диска нет, и база с фото сотрутся при перезапуске).
3. Когда Render спросит значения переменных, заполните:
   - `SITE_URL` — адрес сайта (сначала `https://<имя>.onrender.com`, потом свой домен);
   - `ADMIN_PATH` — секретный адрес админки (например `staff-k29x`);
   - `ADMIN_BOOTSTRAP_EMAIL` и `ADMIN_BOOTSTRAP_PASSWORD` — первый администратор (пароль от 10 символов, буквы и цифры). **После первого входа удалите эти две переменные.**
   - `SMTP_HOST/USER/PASS` — почта (необязательно сразу), `YANDEX_GEOCODER_KEY` — ключ геокодера (рекомендуется).
4. После запуска откройте `https://<адрес>/<ADMIN_PATH>`, войдите, проверьте «Настройки», пройдите чек-лист выше.
5. Свой домен: Render → Settings → Custom Domains, затем обновите `SITE_URL`.

Здоровье сервиса: `/healthz`. Резервная копия: скачивайте `/data/shop.db` и `/data/uploads` (Render → Shell или через снапшоты диска).
Меню и фото из `public/menu/` попадут в новую базу автоматически при первом запуске; цены, которые вы поменяли локально, нужно задать заново в админке (или перенести файл `data/shop.db` на диск).

## Водяной знак на фото блюд
Исходные фото хранятся в `assets/menu-originals/`, готовые (с знаком, пропорции 4:3) — в `public/menu/`. Знак: `assets/watermark-source.png`.
Заново нанести знак на все фото: `node scripts/apply-watermark.js` (оригиналы не меняются). Размер и отступ — в `server/lib/watermark.js`. Фото раздела «Лапша и рис» остаются в исходных размерах, знак на них меньше (чтобы не закрывать подписи цен).
Фото, загруженные в админке («Меню → Изменить блюдо → Фото»), получают знак автоматически.
